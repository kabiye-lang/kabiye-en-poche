# mobile gotchas

- Uniwind's Metro resolver replaces every `react-native` import with a fixed export list. A dependency that uses a newer RN export crashes at launch with `Cannot read property 'X' of undefined` (expo-asset and `AssetRegistry` on RN 0.88, uni-stack/uniwind#732). Check: the red-box stack names the dependency. Route its import around Uniwind in `metro.config.js`.
- An app built with Xcode 27 must use the iOS scene life cycle, so SDK 57 builds exit at launch on this Mac ("UIScene life cycle is required"). Check: `xcodebuild -version` before you plan a local run of an older SDK.
- Top-level keys in `locales/*.json` go to both iOS and Android. Put iOS-only keys (InfoPlist names like `NS…UsageDescription`) under `"ios"`, or Android `lintVitalRelease` fails with `ExtraTranslation`. Check: `./gradlew app:assembleRelease` without `-x`.
- A lesson or unit counts as written, and a learner can open it, only when its `status` is `available` or null (`utils/lesson-status.ts` `isWritten`). A `maintenance` lesson is listed as "Being corrected" but cannot be opened. The column defaults to `coming_soon`, and content alone opens nothing: in 2026-09 Foundations II shipped 4 complete lessons no learner could open. The crawler's `import_json` now calls `publish_lesson`. Check: after a direct database write, `select status from lessons where id = …`.
- An unbuilt (`coming_soon`) lesson never gates the built lesson after it (`utils/lesson-locks.ts`). Under the old "previous lesson completed" rule, one unbuilt lesson locked its unit forever. Check: `utils/__tests__/lesson-locks.test.ts`.
- A `fill_blank` sentence must hold `___`: `fill-blank-step.tsx` splits on it. Without it the step showed the English sentence with no gap (2026-09-08). Check: the crawler's `wrong-shape` gate.
- A prose example whose `kbp` holds a space is a phrase, not a taught word: `build-lesson-steps.ts` gives it no card. Check: the crawler's `note-on-phrase` gate.
- `audio`, `listen_choose` and `listen_type` drop out at runtime without a usable recording (`build-lesson-steps.ts`, `utils/audio-source`). The crawler no longer generates them (`schema.GENERATABLE_TYPES`).
